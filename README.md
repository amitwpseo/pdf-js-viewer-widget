# pdf-js-viewer-widget

An HTML, CSS, and JavaScript widget that renders PDF documents using PDF.js.

## Overview

This snippet provides an interactive PDF viewer embedded within a styled web section. It loads a remote PDF using PDF.js and provides UI controls for viewing and interacting with the document.

## Features

- **Canvas Rendering**: Displays PDF pages on an HTML5 canvas via PDF.js.
- **Page Navigation**: Includes previous and next buttons, keyboard arrow navigation, and touch swipe gestures.
- **Thumbnail Strip**: Generates dynamic thumbnail previews for jumping to specific pages.
- **Zoom Controls**: Supports zooming in and zooming out with an updated percentage indicator.
- **Download & Fallback**: Includes a direct link to download/open the PDF and an error display state if loading fails.
- **Responsive Design**: Adapts canvas sizing and controls for mobile screens.
